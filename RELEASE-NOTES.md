# CLOCK Screen Saver 0.1.1

CLOCK Screen Saver displays a configurable clock on Windows 10 and 11. Choose a clock face, time zone, time format and display layout, or import a CLOCK share link. The screen saver shows the PC clock when the online clock is unavailable.

Save `Clock.scr` in a permanent location, right-click it and choose **Install**. To uninstall, select a different screen saver or **(None)** in Windows Screen Saver Settings and delete the file. See the [installation guide](https://github.com/geniuskey/clock-screensaver#설치와-설정).
